COMO JUGAR EN 3 SIMPLES PASOS:
--------------------------------------------------------------------------------

1. Copia tu disco original de Alundra en formatos .BIN/.CUE, .ISO, .PBP o .CHD
   en la carpeta 'alundra_disc\'.
   
2. Haz doble clic en 'PREPARAR_DISCO.bat' (detectara tu version y region en 1 segundo).

3. ¡Listo! Para jugar tienes varias opciones:
   - 'Alundra.exe' : Lanzador silencioso de maximo rendimiento (autodetecta monitor).
   - 'JUGAR_ALUNDRA.bat' : Lanzador estandar 16:9 Panoramico 4K.
   - 'JUGAR_ALUNDRA_21_9_ULTRAWIDE.bat' : Modo 21:9 Ultra-Panoramico.
   - 'JUGAR_ALUNDRA_4K_43.bat' : Modo 4:3 Clasico Pixel-Perfect.

--------------------------------------------------------------------------------
CONTROLES POR DEFECTO:
--------------------------------------------------------------------------------
- Teclado:
  * Flechas : Mover a Alundra
  * Z : Saltar
  * X : Atacar / Usar espada o herramienta
  * C : Interactuar / Hablar / Coger objetos
  * Enter : Pausa / Menu de Inventario

- Mandos Xbox / PlayStation / DirectInput:
  * Stick izquierdo / Cruceta : Mover a Alundra
  * Boton A / Cruz : Saltar
  * Boton X / Cuadrado : Atacar
  * Boton B / Circulo : Interactuar / Accion
  * Start : Menu / Inventario
